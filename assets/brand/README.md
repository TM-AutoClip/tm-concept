# Brand assets

The TM Concept logo set: icon (`tm-concept-icon*.svg`, 1024 px PNG), glyph (`tm-concept-glyph*.svg`) and horizontal logos
(light and dark backgrounds). Colors: navy `#0B1633`, amber `#FFB224`, light `#EAF2FF` (coral variant `#FF6B57`).
`tm-concept.ico` (16–256 px) and `tm-concept-icon-256.png` are generated from `tm-concept-icon-1024.png`.
