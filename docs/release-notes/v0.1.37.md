# TM Concept 0.1.37

[English](#english) · [Türkçe](#türkçe)

## English

### What changed since 0.1.36

**Which file to download**
- **`TMConcept-win-x64-Setup.exe` — installed edition (recommended on Windows).** Installs for your user only and updates itself.
- **`TMConcept-Portable-win-x64.exe` — portable edition.** One program file, nothing installed.
- **Linux:** `tm-concept-portable-linux-x64.tar.gz` or `tm-concept-portable-linux-arm64.tar.gz`.
- The `.nupkg`, `.AppImage` and `releases.*.json` files are for the installed edition's updates. The installed 0.1.36 updates itself.

**Less disk space left behind**
- **Old components folders are cleaned at start.** When "Reinstall from scratch" was cut short (the app closed or the computer turned off
  in the middle), the old `tools.old-…` / `tools.failed-…` folders next to the components folder stayed for good, often gigabytes. Now they
  are deleted at the next start, in the background after the window opens (the start does not wait). Only folders with exactly that name
  next to the components folder are taken; nothing while an install or a reinstall runs. Right after a cut-short reinstall they stay for
  one more start (they may hold the components that worked; Settings → Storage lists them). A folder with a file in use is tried again at
  the next start. What was freed is shown in the activity panel.
- **The video engines' npm cache stays in the app's folder.** It went to the system's `npm-cache` folder before, where the app never
  removed it; now it is inside the engine's own components folder, so Settings → Storage counts it and the full delete takes it.
- **The Python voices' download cache is pruned** after each install of the Python or a voice environment (`uv cache prune`); a failed
  prune only writes a warning to the log, the install stays.
- **The engines' temporary folders** (`tools/engines/<engine>/tmp`) are deleted when an install ends, and what is left is swept at start.

**For developers**
- New: `ILeftoverSweep` / `LeftoverSweep` (Core, `DiskSpace`: decides from folder lists only), `ILeftoverSweeper` / `LeftoverSweeper`
  (Desktop, `DiskSpace`), `IComponentWorkGate` / `ComponentWorkGate` (Desktop, `Components`; a reinstall keeps a `tools.reinstalling`
  marker file until it ends), `EnginePackage.NpmCache` / `TempFolder` / `PackageEnvironment()`, `PythonInstaller.PruneArguments()`.
  The log has a `startup.leftover_sweep <ms>` line. `OnlineVoiceTests` use the test run's one temporary folder. No database change.

## Türkçe

### 0.1.36 sürümünden bu yana değişenler

**Hangi dosyayı indirmeli**
- **`TMConcept-win-x64-Setup.exe` — kurulan tür (Windows'ta önerilen).** Yalnız senin kullanıcın için kurulur ve kendini günceller.
- **`TMConcept-Portable-win-x64.exe` — taşınabilir tür.** Tek program dosyası, hiçbir şey kurulmaz.
- **Linux:** `tm-concept-portable-linux-x64.tar.gz` ya da `tm-concept-portable-linux-arm64.tar.gz`.
- `.nupkg`, `.AppImage` ve `releases.*.json` dosyaları kurulan türün güncellemeleri içindir. Kurulu 0.1.36 kendini günceller.

**Diskte daha az artık**
- **Eski bileşen klasörleri açılışta temizleniyor.** "Sıfırdan yeniden kur" yarıda kesildiğinde (program kapandı ya da bilgisayar kapandı)
  bileşen klasörünün yanında kalan `tools.old-…` / `tools.failed-…` klasörleri, çoğu zaman gigabaytlarca, hep kalıyordu. Artık bir sonraki
  açılışta, pencere açıldıktan sonra arka planda siliniyor (açılış beklemiyor). Yalnız bileşen klasörünün yanındaki, adı tam bu kalıpta
  olan klasörler alınır; bir kurulum ya da yeniden kurulum sürerken hiçbirine dokunulmaz. Yarıda kesilen yeniden kurulumdan hemen sonra bir
  açılış daha durur (çalışan bileşenler onlarda olabilir; Ayarlar → Depolama listeler). İçinde kullanımda dosya olan klasör bir sonraki
  açılışta yeniden denenir. Ne kadar yer açıldığı işlem panelinde yazar.
- **Video motorlarının npm önbelleği programın klasöründe.** Önceden sistemin `npm-cache` klasörüne gidiyordu ve program onu hiç
  silmiyordu; artık motorun kendi bileşen klasöründe, Ayarlar → Depolama onu da sayar, tam silme onu da kaldırır.
- **Python seslerinin indirme önbelleği budanıyor:** Python'un ya da bir ses ortamının her kurulumundan sonra (`uv cache prune`); budama
  başarısız olursa yalnız günlüğe uyarı düşer, kurulum bozulmaz.
- **Motorların geçici klasörleri** (`tools/engines/<motor>/tmp`) kurulum bitince siliniyor, kalan olursa açılışta süpürülüyor.

**Geliştiriciler için**
- Yeni: `ILeftoverSweep` / `LeftoverSweep` (Core, `DiskSpace`: yalnız klasör listesinden karar verir), `ILeftoverSweeper` /
  `LeftoverSweeper` (Desktop, `DiskSpace`), `IComponentWorkGate` / `ComponentWorkGate` (Desktop, `Components`; yeniden kurulum bitene
  kadar `tools.reinstalling` işaret dosyasını tutar), `EnginePackage.NpmCache` / `TempFolder` / `PackageEnvironment()`,
  `PythonInstaller.PruneArguments()`. Günlükte `startup.leftover_sweep <ms>` satırı var. `OnlineVoiceTests` test çalışmasının tek geçici
  klasörünü kullanıyor. Veritabanı değişmedi.
