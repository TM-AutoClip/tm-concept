# TM Concept 0.1.38

[English](#english) · [Türkçe](#türkçe)

## English

### What changed since 0.1.37

**Which file to download**
- **`TMConcept-win-x64-Setup.exe` — installed edition (recommended on Windows).** Installs for your user only and updates itself.
- **`TMConcept-Portable-win-x64.exe` — portable edition.** One program file, nothing installed.
- **Linux:** `tm-concept-portable-linux-x64.tar.gz` or `tm-concept-portable-linux-arm64.tar.gz`.
- The `.nupkg`, `.AppImage` and `releases.*.json` files are for the installed edition's updates. The installed 0.1.37 updates itself.

**A window at once when you start the app**
- **Splash window.** A double-click now shows a small window with the logo right away: "Starting TM Concept…" and the step it is at
  (Preparing · Components · Vault · Database · Session), with a progress bar. Before, nothing appeared for some seconds until the main
  window was ready.
- **The start works in the background.** Building the app's parts, the saved model catalog, the check for processes an earlier run left,
  opening the encrypted database (and bringing an older one up to date), reading the settings and cleaning old work files no longer run on
  the window's thread.
- **Cancel.** The splash window's Cancel ends the start: processes the app started are ended, the data folder is freed and the app closes.
  It is safe at any step; an older database is upgraded on a copy, so a cut-short upgrade leaves the file as it was.
- **When the start fails** the splash window says at which step and why, and its button becomes Close; the main window does not open.
- **With a master password** the splash closes and the password window opens (never two windows on top of each other). A second start
  while the app is starting brings the splash to the front.
- **After the main window opens**, removing the previous version's program file and the daily backup run in the background; the app can be used while the backup is made.

**For developers**
- New in `Startup`: `IStartupSequence` / `StartupSequence` (runs the start steps in order off the interface thread), `IStartupScreen`,
  `IStartupExit` / `StartupExit`, `AppBoot` (the start before the services exist), `StartupStage`, `StartupOutcome`, `StartupStep`,
  `StartupSplash`; `SplashWindow` + `SplashViewModel`. `Main` keeps only Velopack, the options, the install folder check, the instance lock
  and the preferences file. `Vault.OpenAsync(keyOpened, …)` reports when the key is open. The log has a `startup.at.splash <ms>` line.
  No database change.

## Türkçe

### 0.1.37 sürümünden bu yana değişenler

**Hangi dosyayı indirmeli**
- **`TMConcept-win-x64-Setup.exe` — kurulan tür (Windows'ta önerilen).** Yalnız senin kullanıcın için kurulur ve kendini günceller.
- **`TMConcept-Portable-win-x64.exe` — taşınabilir tür.** Tek program dosyası, hiçbir şey kurulmaz.
- **Linux:** `tm-concept-portable-linux-x64.tar.gz` ya da `tm-concept-portable-linux-arm64.tar.gz`.
- `.nupkg`, `.AppImage` ve `releases.*.json` dosyaları kurulan türün güncellemeleri içindir. Kurulu 0.1.37 kendini günceller.

**Programı açınca hemen bir pencere**
- **Açılış penceresi.** Çift tıklayınca artık hemen logolu küçük bir pencere açılıyor: "TM Concept başlatılıyor…" ve o anki adım
  (Hazırlanıyor · Bileşenler · Kasa · Veritabanı · Oturum), ilerleme çubuğuyla. Önceden ana pencere hazır olana kadar birkaç saniye hiçbir
  şey görünmüyordu.
- **Açılış arka planda.** Programın parçalarının kurulması, kayıtlı model kataloğu, önceki çalışmadan kalan süreçlerin denetimi, şifreli
  veritabanının açılması (eskiyse güncellenmesi), ayarların okunması ve eski iş dosyalarının temizlenmesi artık pencerenin iş
  parçacığında yapılmıyor.
- **İptal.** Açılış penceresindeki İptal açılışı bitirir: programın başlattığı süreçler kapatılır, veri klasörü serbest bırakılır ve
  program kapanır. Her adımda güvenli; eski veritabanı bir kopya üzerinde güncellenir, yarıda kesilen güncelleme dosyayı olduğu gibi bırakır.
- **Açılış başarısız olursa** açılış penceresi hangi adımda ve neden olduğunu yazar, düğmesi Kapat olur; ana pencere açılmaz.
- **Ana parola varsa** açılış penceresi kapanır, parola penceresi açılır (iki pencere üst üste kalmaz). Açılış sürerken programı yeniden
  başlatmak açılış penceresini öne getirir.
- **Ana pencere açıldıktan sonra** önceki sürümün program dosyasının silinmesi ve günlük yedek arka planda yapılır; yedek alınırken program kullanılabilir.

**Geliştiriciler için**
- `Startup` altında yeni: `IStartupSequence` / `StartupSequence` (açılış adımlarını sırayla, arayüz iş parçacığı dışında çalıştırır),
  `IStartupScreen`, `IStartupExit` / `StartupExit`, `AppBoot` (servisler kurulmadan önceki açılış), `StartupStage`, `StartupOutcome`,
  `StartupStep`, `StartupSplash`; `SplashWindow` + `SplashViewModel`. `Main`'de yalnız Velopack, seçenekler, kurulum klasörü denetimi,
  tek örnek kilidi ve tercih dosyası kaldı. `Vault.OpenAsync(keyOpened, …)` anahtarın açıldığını bildirir. Günlükte
  `startup.at.splash <ms>` satırı var. Veritabanı değişmedi.
