# TM Concept 0.1.17

[English](#english) · [Türkçe](#türkçe)

## English

### What changed since 0.1.16

**One model on the graphics card at a time**
- Local and online models now run through one pipeline. Online models start at once. A local model takes the graphics card, and
  the model that held it before is unloaded first (Ollama, LM Studio, stable-diffusion.cpp, the Python voices). Two local models
  never share the card.
- Free graphics memory is measured right before each local model (Windows: the system's GPU memory counters and DXGI; Linux: sysfs
  and nvidia-smi), so memory used by Windows and other programs is taken into account.
- Cards are grouped into memory classes: 4, 6, 8, 12, 16, 24 and 32 GB. A card sees the models of its own class and the lower ones.
- The card is also freed when the video queue ends and when the app closes. Models left in Ollama or LM Studio from an earlier run are
  unloaded before the first local model takes the card.

**Local images**
- stable-diffusion.cpp is updated (Windows master-1106, Linux master-1043) and runs FLUX.3.
- 17 local image models in memory classes (FLUX.2 klein, FLUX.3, Z-Image, SD 3.5, SDXL Lightning, Qwen-Image and others). Each one
  shows its class: green when the card covers it, red when it does not, yellow on the processor build or an unknown card.
- Memory options come from the free memory: VAE tiling and a memory reserve always, moving weights to main memory when the card is
  too small, and one lower step when sd-cli runs out of memory. This fixes the full-quality Z-Image failure on a 16 GB AMD card;
  full-quality (BF16) Z-Image now needs a 24 GB card, and a Q8 variant was added for 12 GB.
- Models that are free only for non-commercial use carry a red badge and ask once for licence acceptance before the first download.

**Voices**
- New Python voices: XTTS-v2, F5-TTS Turkish, VoxCPM2, Trendyol-TTS, Ahenk and MMS-TTS Turkish. Each voice family gets its own
  Python environment; NVIDIA cards (driver 570+, compute capability 7.0+) use CUDA, others use the processor. XTTS-v2, F5-TTS and
  MMS are non-commercial.
- New Ahenk Cep: a small Turkish voice (CC BY 4.0) that runs on the processor.
- Turkish reading rules for every Turkish narration: numbers, dates, times, percentages, currencies, units, Roman numerals and
  abbreviations are written out before the voice speaks. The built-in pronunciation list grows to several hundred words
  (e.g. Google → Gugıl). Settings → Speech and pronunciation has search, categories, edit and Listen.
- **Nothing is downloaded on its own.** The Python base (uv, Python), each voice environment and each model are separate components;
  models download only when you install them in the components window or choose them for a step and confirm.

**Ollama and LM Studio**
- Settings → API keys finds Ollama and LM Studio running on this computer. Their models (with context, images and thinking support)
  appear in every text step. Ollama runs through its own API (context sent with each request, JSON format, optional "Think first");
  LM Studio models are loaded with the chosen context and unloaded when another local model needs the card.

**Sturdier answers**
- An unreadable JSON answer is asked again twice; after the third try the step stops with a clear error. Thinking text, code fences,
  trailing commas and text around the JSON are handled.
- The topic suggestion answer limit is a setting (Settings → General, default 16 000 tokens).

**Updates and data**
- The app checks GitHub once a day for a new version and offers it in a window; it downloads only when you confirm, checks the
  SHA-256 and restarts. It can be turned off in Settings → General.
- The database now upgrades itself step by step from one version to the next, on a copy, with a backup first. A database from
  0.1.16 or earlier cannot be upgraded; the app offers to set it aside and start fresh.
- Downloads retry and resume after a break, a full disk is reported as such, and the components that were installed are remembered,
  so the update question works again after a reinstall.

**Fixes**
- "No subtitles" now really leaves the subtitles out.
- Model and voice choices are kept as soon as they change; they no longer reset.
- A new log page (bottom panel → Show all) with day, level and search filters and a live view.

**Not yet tried on real hardware:** the Python voices with torch, sd-cli 1106/1043 on a real card, the new image models above 6 GB,
real Ollama and LM Studio servers, and the self-update. Reports are welcome.

## Türkçe

### 0.1.16'dan bu yana değişenler

**Ekran kartında aynı anda tek model**
- Yerel ve çevrimiçi modeller artık tek akışta çalışıyor. Çevrimiçi modeller hemen başlar. Yerel model ekran kartını alır; önce kartı
  tutan model boşaltılır (Ollama, LM Studio, stable-diffusion.cpp, Python sesleri). İki yerel model kartı asla paylaşmaz.
- Her yerel modelden hemen önce boş ekran kartı belleği ölçülür (Windows: sistemin GPU bellek sayaçları ve DXGI; Linux: sysfs ve
  nvidia-smi); Windows'un ve diğer programların kullandığı bellek hesaba katılır.
- Kartlar bellek sınıflarına ayrıldı: 4, 6, 8, 12, 16, 24 ve 32 GB. Bir kart kendi sınıfının ve alt sınıfların modellerini görür.
- Video kuyruğu bitince ve program kapanınca kart boşaltılır. Önceki çalışmadan Ollama ya da LM Studio'da kalan modeller, ilk yerel
  model kartı almadan önce boşaltılır.

**Yerel görseller**
- stable-diffusion.cpp güncellendi (Windows master-1106, Linux master-1043) ve FLUX.3'ü çalıştırıyor.
- Bellek sınıflarında 17 yerel görsel modeli (FLUX.2 klein, FLUX.3, Z-Image, SD 3.5, SDXL Lightning, Qwen-Image ve diğerleri). Her biri
  sınıfını gösterir: kart yetiyorsa yeşil, yetmiyorsa kırmızı, işlemci sürümünde ya da kart bilinmiyorsa sarı.
- Bellek ayarları boş belleğe göre yapılır: VAE döşeme ve bellek payı her zaman; kart küçükse ağırlıklar ana belleğe alınır; sd-cli'nin
  belleği biterse bir alt basamakla yeniden denenir. 16 GB AMD kartta tam kalite Z-Image hatası bununla giderildi; tam kalite (BF16)
  Z-Image artık 24 GB kart istiyor, 12 GB için Q8 sürümü eklendi.
- Yalnız ticari olmayan kullanıma açık modellerde kırmızı rozet var; ilk indirmeden önce bir kez lisans onayı istenir.

**Sesler**
- Yeni Python sesleri: XTTS-v2, F5-TTS Türkçe, VoxCPM2, Trendyol-TTS, Ahenk ve MMS-TTS Türkçe. Her ses ailesinin kendi Python ortamı
  var; NVIDIA kartlar (sürücü 570+, işlem yeteneği 7.0+) CUDA'yı, diğerleri işlemciyi kullanır. XTTS-v2, F5-TTS ve MMS ticari değildir.
- Yeni Ahenk Cep: işlemcide çalışan küçük bir Türkçe ses (CC BY 4.0).
- Her Türkçe seslendirmeye Türkçe okuma kuralları: sayılar, tarihler, saatler, yüzdeler, para birimleri, birimler, Roma rakamları ve
  kısaltmalar ses konuşmadan önce yazıya çevrilir. Hazır telaffuz listesi birkaç yüz kelimeye çıktı (ör. Google → Gugıl).
  Ayarlar → Ses ve telaffuz: arama, kategoriler, düzenleme ve Dinle.
- **Hiçbir şey kendiliğinden inmez.** Python altyapısı (uv, Python), her ses ortamı ve her model ayrı bileşendir; modeller yalnız
  bileşen penceresinden kurduğunda ya da bir adım için seçip onayladığında iner.

**Ollama ve LM Studio**
- Ayarlar → API anahtarları bu bilgisayarda çalışan Ollama ve LM Studio'yu bulur. Modelleri (bağlam, görsel ve düşünme desteğiyle)
  her metin adımında sunulur. Ollama kendi API'siyle çalışır (bağlam her istekte gönderilir, JSON biçimi, isteğe bağlı "Önce düşünsün");
  LM Studio modelleri seçilen bağlamla yüklenir ve başka bir yerel model kartı isteyince boşaltılır.

**Daha sağlam yanıtlar**
- Okunamayan bir JSON yanıtı iki kez daha istenir; üçüncü denemeden sonra adım açık bir hatayla durur. Düşünme metni, kod çitleri,
  sondaki virgüller ve JSON'un çevresindeki metin işlenir.
- Konu önerisi yanıt sınırı bir ayar oldu (Ayarlar → Genel, varsayılan 16 000 token).

**Güncellemeler ve veri**
- Program günde bir kez GitHub'da yeni sürüm arar ve bir pencerede sunar; yalnız onaylarsan indirir, SHA-256'yı denetler ve yeniden
  başlar. Ayarlar → Genel'den kapatılabilir.
- Veritabanı artık sürümden sürüme adım adım, önce yedek alınarak, bir kopya üzerinde kendini yükseltiyor. 0.1.16 ve öncesinin
  veritabanı yükseltilemez; program onu kenara koyup temiz başlamayı önerir.
- İndirmeler kopunca yeniden dener ve kaldığı yerden sürer, dolu disk kendi adıyla bildirilir, kurulan bileşenler hatırlanır; yeniden
  kurulumdan sonra güncelleme sorusu yine çalışır.

**Düzeltmeler**
- "Altyazı yok" artık altyazıyı gerçekten çıkarıyor.
- Model ve ses seçimleri değiştiği anda kaydediliyor; artık kendiliğinden sıfırlanmıyor.
- Yeni günlük sayfası (alt panel → Tümünü göster): gün, düzey ve arama süzgeci, canlı izleme.

**Henüz gerçek donanımda denenmedi:** torch'lu Python sesleri, gerçek kartta sd-cli 1106/1043, 6 GB üstü yeni görsel modelleri, gerçek
Ollama ve LM Studio sunucuları ve kendi kendini güncelleme. Geri bildirimler memnuniyetle karşılanır.
