# TM Concept 0.1.11

[English](#english) · [Türkçe](#türkçe)

## English

### What changed since 0.1.10

**Video code: SVG no longer trips the safety check**
- A video could fail with "The video code was rejected by the safety check" when the code model wanted SVG shapes: the prompt only said
  "no web addresses", so the model built the SVG namespace from pieces (the check refuses a lone `http:`) and, in its one repair, parsed
  markup with `DOMParser` (refused too). Nothing harmful was in the code.
- The video code prompt and its repair request now say it plainly: SVG elements are made with `document.createElementNS` and the SVG
  namespace written as one whole string (it is allowed); markup is never parsed (no `innerHTML`, `DOMParser`, `createContextualFragment`,
  `document.write`). The safety check itself did not change. Prompt version 6.

**Data**
- The database and the backup format did not change: a 0.1.10 data folder and its backups open as they are.

## Türkçe

### 0.1.10'dan bu yana değişenler

**Video kodu: SVG artık güvenlik denetimine takılmıyor**
- Kod modeli SVG şekil kullanmak isteyince video "Video kodu güvenlik denetiminden geçmedi" diye başarısız olabiliyordu: istem yalnız
  "web adresi yok" diyordu; model SVG adresini parça parça kurdu (denetim tek başına `http:`'yi reddeder), tek onarımında da `DOMParser`
  ile işaretleme ayrıştırdı (o da yasak). Kodda zararlı bir şey yoktu.
- Video kodu istemi ve onarım isteği artık açıkça söylüyor: SVG öğeleri `document.createElementNS` ile ve SVG adresi tek parça yazılarak
  yapılır (izinli); işaretleme hiç ayrıştırılmaz (`innerHTML`, `DOMParser`, `createContextualFragment`, `document.write` yok). Denetimin
  kendisi değişmedi. İstem sürümü 6.

**Veri**
- Veritabanı ve yedek biçimi değişmedi: 0.1.10 veri klasörü ve yedekleri olduğu gibi açılır.
