# TM Concept 0.1.14

[English](#english) · [Türkçe](#türkçe)

## English

### What changed since 0.1.13

**0.1.13 did not start**
- 0.1.13 stopped at once with "Metadata is already set for Icon on Avalonia.Controls.Window": the app icon was given to every window
  through property metadata, which the window itself already sets. The tests never ran that start-up step, so it was not caught.
  Every window now takes the icon from a style in `App.axaml`; a test checks that every window type shows it.

**Taskbar icon, found on the running app**
- The taskbar button showed Windows' generic "application" icon, in 0.1.12 too, although the window answered with the app icon and the
  exe carries it. Without an id of its own the taskbar took the icon by the exe path and never asked the window again.
- Now the open window gets the app's own taskbar id (`TMAutoClip.TMConcept`) with the relaunch command, name and icon a pinned button
  needs; the taskbar then shows the app icon. The full-screen player gets the same id, so it shows the same icon.
- Seen on the real app: the button shows the logo; before, the generic icon.

## Türkçe

### 0.1.13'ten bu yana değişenler

**0.1.13 açılmıyordu**
- 0.1.13 açılır açılmaz "Metadata is already set for Icon on Avalonia.Controls.Window" hatasıyla kapanıyordu: simge bütün pencerelere
  özellik varsayılanıyla verilmişti, pencere bunu zaten kendisi ayarlıyor. Testler bu açılış adımını hiç çalıştırmadığı için
  yakalanmadı. Artık her pencere simgeyi `App.axaml`'daki bir stilden alıyor; her pencere türünde simgenin olduğunu bir test denetliyor.

**Görev çubuğu simgesi, çalışan programda bulundu**
- Görev çubuğu düğmesi Windows'un genel "uygulama" simgesini gösteriyordu (0.1.12'de de); oysa pencere de exe de programın simgesini
  taşıyordu. Kendi kimliği olmayınca görev çubuğu simgeyi exe yolundan alıyor, pencereye bir daha sormuyordu.
- Artık açılan pencereye programın kendi görev çubuğu kimliği (`TMAutoClip.TMConcept`), sabitlenmiş düğmenin ihtiyaç duyduğu yeniden
  başlatma komutu, adı ve simgesiyle veriliyor; görev çubuğu programın simgesini gösteriyor. Tam ekran oynatıcı da aynı kimliği alıyor.
- Gerçek programda görüldü: düğmede logo var; önceden genel simge vardı.
