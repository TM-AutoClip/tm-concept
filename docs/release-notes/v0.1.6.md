# TM Concept 0.1.6

[English](#english) · [Türkçe](#türkçe)

## English

Models are chosen on the page that uses them and remembered per profile, a missing API key is asked for before anything starts, a
restored older backup no longer breaks "Add profile", backups can hold your API keys when you choose, and two more local options.

### What changed since 0.1.5

**Models are chosen on their pages**
- Settings → **Models** is gone; nothing about models is in Settings any more.
- **Generate concepts**: the concept model (with its effort) and the *duplicate check by meaning* (off, local or online).
- **Concept → video**: the video code model with its effort and the video engine, **images** (off, the profile's sample images, an online
  or a local image model) and **narration** (off, a local or an online voice, with voice, speed and ▶ Listen). Subtitles and the narration
  file stay per queued concept.
- **Profile**: the model of "Describe with a model", under the sample images (where it is used).
- The choices are saved **per profile** when a process starts (no Save button) and shown again the next time that profile is opened. A new
  profile starts with nothing paid chosen; the "Recommended" chips stay.
- When you start (Generate, Produce, Describe, ▶ Listen): a required model that is not chosen, a license you decline, or a choice that
  needs a download you decline or that fails stops it before anything is sent or paid for; the reason is on the page and in the log.
  Downloads are still listed in **one** confirmation and installed with progress.

**API key gate**
- A chosen online model whose provider has no API key stops the start and names the provider. A window opens right there with the
  provider's guide: paste the key, **Test and save** — it is tested with the provider's free request and kept only when the test passes
  (fal has no free test: its key is kept with a note and checked at its first use). Then the process continues on its own.
- The gate asks for a **working** key: a saved key that never passed its test (for example one 0.1.5 kept although its test failed, or a
  restored one) is tested once with the free request before the start; if it fails, the key window opens. Settings → API keys now also
  tests a new key first and saves it only when it works. Of several keys, one that passed its test is used.

**Estimates**
- The concept estimate follows the model chosen on the page; with no profile selected it says so (0.1.5 kept saying "choose a model").
  The semantic check's cost is included (local: free).
- The video page shows the estimate of the queued videos with the chosen models (code call and one possible repair, image prompts and
  images, an online voice's characters) and, after a video, its exact cost. "This month" moved to the Produced videos page.

**Database fix**
- Cause of "no such table: profile_step_models" when saving a new profile: a backup restored at the first start was installed without
  bringing its schema to the current version (only a normal start did that). A 0.1.4 backup restored in 0.1.5 therefore lacked the new
  table until the next start. Now every way a database comes in (new, unlock, restore) goes through the same versioned upgrade (`PRAGMA
  user_version`), and a test compares a new file with upgraded ones table by table and column by column and reads every table and column
  the app uses in both.
- 0.1.5 → 0.1.6: the general model defaults of Settings → Models become each profile's own choices (where the profile had none), then
  that table goes.

**Backups**
- You choose what goes in: **API keys**, **profiles** (with their model choices and their sample image files), **concepts** (the trash,
  the video list and costs too), **settings**. *Back up now* asks every time (API keys unticked); automatic backups (daily and before a
  large change) keep a saved choice, by default everything except the API keys. Keys may go in only because the file is encrypted with
  your backup password (Argon2id + AES-256-GCM).
- *Back up now* files have their own name (`tm-concept-manual-…`) and their own last ten; they never push the daily backups out and never
  count as the day's backup. The backup before a large change (a profile deleted, 20+ concepts deleted for good) always holds the
  profiles and the concepts, whatever the automatic choice is.
- A backup made by a newer version (or one whose upgrade fails) is refused before anything is installed; the data folder stays empty and
  another backup can be restored. When no backup password is set, Settings → Backup now lets you set one.
- Format 03. A restore first shows what the file holds and asks; then it brings back exactly that. A different image file already in
  place is moved aside, never overwritten. 0.1.1–0.1.5 backups (format 02) still restore.
- **Changing the backup password needs the current one**; a wrong one is refused and logged (without any password). The app has no
  master password change screen; the master password is only set at the first start.

**Local options**
- **Kokoro 82M** (local, free): a second local voice of good quality, **English only** (27 American and British voices). sherpa-onnx 2.x
  reads English from the model's own dictionary (no espeak-ng), so Turkish profiles do not offer it; Turkish stays with Supertonic 3.
  Numbers are spelled out before speaking as plain dictionary words ("1453" → "fourteen fifty three", "1990s" → "nineteen nineties",
  "21st" → "twenty first"). It is a **dictionary voice**: a word its dictionary does not know (most names, coined words) is left out of
  the audio. The video then gets a warning (the subtitles still show the words); for texts full of names Supertonic suits better. All
  voices, the British ones too, use the American English dictionary.
- A saved narration choice that the page no longer offers (for example Kokoro after the profile's language became Turkish) shows "off"
  and is saved as off when the process starts; a voice that does not speak the content language is never used.
- **Multilingual MiniLM** (local, free): the duplicate check by meaning without an API, on the processor, 50+ languages including Turkish
  and English. It uses the ONNX Runtime that comes with the sherpa-onnx libraries (nothing extra in the app). The concepts made before it
  was turned on are embedded at its first run (the newest 300 per run), so they are compared too. Its thresholds are the same as for the
  online models and not measured on real lists yet.

### Licenses of the new local models (checked on 2026-11-06)

- Kokoro-82M (hexgrad): Apache-2.0, not gated; the int8 archive of the sherpa-onnx `tts-models` release (LICENSE: Apache-2.0). The archive
  also holds espeak-ng data (GPL-3.0); sherpa-onnx 2.x does not use it and the app deletes it right after unpacking.
- sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2: Apache-2.0, not gated; the repository's own int8 ONNX file and tokenizer at
  commit `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`, each with its SHA-256.
- Not added: Orpheus (large), Pocket TTS (English only and it works by cloning a reference voice, which TM Concept does not do), Piper /
  Kitten / Matcha (need espeak-ng, GPL).

## Türkçe

Modeller onları kullanan sayfada seçilir ve profil başına hatırlanır, eksik API anahtarı iş başlamadan sorulur, geri yüklenen eski yedek
artık "Profil ekle"yi bozmaz, yedeğe istersen API anahtarların da girer ve iki yerel seçenek daha var.

### 0.1.5'ten bu yana değişenler

**Modeller kendi sayfalarında seçilir**
- Ayarlar → **Modeller** kalktı; Ayarlar'da modelle ilgili hiçbir şey kalmadı.
- **Konsept üret**: konsept modeli (çabasıyla) ve *anlamca tekrar denetimi* (kapalı, yerel ya da online).
- **Konseptten video**: çabasıyla video kodu modeli ve video motoru, **görseller** (kapalı, profilin örnek görselleri, online ya da yerel
  görsel modeli) ve **seslendirme** (kapalı, yerel ya da online ses; ses, hız ve ▶ Dinle ile). Altyazı ve anlatım dosyası kuyruğa eklenen
  her konseptle saklanmaya devam eder.
- **Profil**: "Modelle açıkla"nın modeli, örnek görsellerin altında (kullanıldığı yerde).
- Seçimler bir iş başlatılınca **profil başına** saklanır (Kaydet düğmesi yok) ve o profil bir dahaki açılışta aynı seçimlerle gelir. Yeni
  profilde ücretli hiçbir şey seçili değildir; "Önerilen" rozetleri yerinde.
- Başlatınca (Üret, Kuyruğu üret, Açıkla, ▶ Dinle): seçilmemiş zorunlu bir model, kabul edilmeyen bir lisans ya da onaylanmayan veya
  başarısız olan bir indirme işi hiçbir şey gönderilmeden, ödenmeden durdurur; sebebi sayfada ve günlükte. İndirmeler yine **tek** onayda
  listelenir ve ilerlemeyle kurulur.

**API anahtarı kapısı**
- Seçilen online modelin sağlayıcısının API anahtarı yoksa iş başlamaz ve sağlayıcının adı söylenir. Oracıkta sağlayıcının rehberiyle bir
  pencere açılır: anahtarı yapıştır, **Dene ve kaydet** — sağlayıcının ücretsiz isteğiyle denenir, yalnız deneme geçerse saklanır (fal'da
  ücretsiz deneme yok: anahtarı bir notla saklanır, ilk kullanımda denetlenir). Sonra iş kendiliğinden devam eder.
- Kapı **çalışan** bir anahtar ister: hiç denemeden geçmemiş kayıtlı bir anahtar (ör. 0.1.5'in denemesi başarısız olsa da sakladığı ya da
  geri yüklenen bir anahtar) başlamadan önce ücretsiz istekle bir kez denenir; geçemezse anahtar penceresi açılır. Ayarlar → API
  anahtarları da artık yeni anahtarı önce dener, yalnız çalışırsa kaydeder. Birden çok anahtardan denemeden geçmiş olan kullanılır.

**Tahminler**
- Konsept tahmini sayfada seçilen modeli izler; profil seçili değilse bunu söyler (0.1.5 "model seç" demeye devam ediyordu). Anlamca
  tekrar denetiminin ücreti de dahil (yerel: ücretsiz).
- Video sayfası seçilen modellerle kuyruktaki videoların tahminini (kod isteği ve olası bir onarım, görsel istemleri ve görseller, online
  sesin karakterleri), bir video bitince de kesin ücretini gösterir. "Bu ay" Üretilen videolar sayfasına taşındı.

**Veritabanı düzeltmesi**
- Yeni profil kaydederken çıkan "no such table: profile_step_models" hatasının sebebi: ilk açılışta geri yüklenen bir yedek, şeması güncel
  sürüme getirilmeden kuruluyordu (bunu yalnız normal açılış yapıyordu). 0.1.5'te geri yüklenen bir 0.1.4 yedeğinde yeni tablo bir sonraki
  açılışa kadar yoktu. Artık veritabanının geldiği her yol (yeni, kilit açma, geri yükleme) aynı sürümlü yükseltmeden geçer (`PRAGMA
  user_version`); bir test yeni dosyayı yükseltilmiş dosyalarla tablo tablo, sütun sütun karşılaştırır ve programın okuduğu her tabloyu ve
  sütunu ikisinde de okur.
- 0.1.5 → 0.1.6: Ayarlar → Modeller'deki genel seçimler, kendi seçimi olmayan her profilin seçimi olur; sonra o tablo kalkar.

**Yedekler**
- İçine neyin gireceğini seçersin: **API anahtarları**, **profiller** (model seçimleri ve örnek görsel dosyalarıyla), **konseptler** (çöp
  kutusu, video listesi ve maliyetler de), **ayarlar**. *Şimdi yedekle* her seferinde sorar (API anahtarları işaretsiz); otomatik yedekler
  (günlük ve büyük bir değişiklikten önce) kayıtlı bir seçimle çalışır, varsayılanı API anahtarları dışında her şey. Anahtarlar yalnız
  dosya yedek parolanla şifrelendiği (Argon2id + AES-256-GCM) için girebilir.
- *Şimdi yedekle* dosyalarının kendi adı (`tm-concept-manual-…`) ve kendi son on dosyası var; günlük yedekleri silmez, günün yedeği
  sayılmaz. Büyük bir değişiklikten önceki yedek (profil silme, 20+ konseptin kalıcı silinmesi) otomatik seçim ne olursa olsun profilleri
  ve konseptleri her zaman içerir.
- Daha yeni bir sürümün yaptığı (ya da yükseltmesi başarısız olan) bir yedek, hiçbir şey kurulmadan reddedilir; veri klasörü boş kalır ve
  başka bir yedek geri yüklenebilir. Yedek parolası yoksa Ayarlar → Yedek artık bir parola belirlemeye izin verir.
- Biçim 03. Geri yükleme önce dosyanın neleri içerdiğini gösterip sorar; sonra tam olarak onu geri getirir. Yerinde farklı bir görsel
  dosyası varsa kenara taşınır, üzerine yazılmaz. 0.1.1–0.1.5 yedekleri (biçim 02) hâlâ geri yüklenir.
- **Yedek parolasını değiştirmek şu anki parolayı ister**; yanlışsa reddedilir ve günlüğe yazılır (parola yazılmaz). Programda ana parola
  değiştirme ekranı yok; ana parola yalnız ilk açılışta belirlenir.

**Yerel seçenekler**
- **Kokoro 82M** (yerel, ücretsiz): kaliteli ikinci bir yerel ses, **yalnız İngilizce** (27 Amerikan ve İngiliz sesi). sherpa-onnx 2.x
  İngilizceyi modelin kendi sözlüğünden okur (espeak-ng yok), bu yüzden Türkçe profillerde çıkmaz; Türkçe için Supertonic 3 kalır.
  Sayılar seslendirmeden önce sözlükteki düz kelimelerle yazılır ("1453" → "fourteen fifty three", "1990s" → "nineteen nineties", "21st"
  → "twenty first"). **Sözlüklü bir sestir**: sözlüğünde olmayan bir kelimeyi (çoğu ad, uydurma kelimeler) seste atlar. Video o zaman bir
  uyarı alır (altyazıda kelimeler yine görünür); adlarla dolu metinlere Supertonic daha uygundur. İngiliz sesleri dahil hepsi Amerikan
  İngilizcesi sözlüğünü kullanır.
- Sayfanın artık sunmadığı kayıtlı bir seslendirme seçimi (ör. profilin dili Türkçe olduktan sonra Kokoro) "kapalı" görünür ve iş
  başlarken kapalı olarak kaydedilir; içerik dilini konuşmayan bir ses hiç kullanılmaz.
- **Multilingual MiniLM** (yerel, ücretsiz): API olmadan anlamca tekrar denetimi; işlemcide, Türkçe ve İngilizce dahil 50'den fazla dil.
  sherpa-onnx kitaplıklarıyla gelen ONNX Runtime'ı kullanır (programa ek bir şey girmedi). Açılmadan önce üretilen konseptler ilk
  çalışmasında vektöre çevrilir (çalışma başına en yeni 300), böylece onlarla da karşılaştırılır. Eşikleri online modellerle aynı ve henüz
  gerçek listelerde ölçülmedi.
