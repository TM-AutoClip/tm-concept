# TM Concept 0.1.0

**English** · [Türkçe](v0.1.0.tr.md)

The first release. TM Concept turns a channel idea into video concepts and short videos with online AI models and your own API keys,
renders the videos on your computer without a GPU and narrates them with a free local voice.

## What is new

- Profiles (channels) with four ready templates (history: Byzantine, Ottoman; technology: ancient, modern), sample images and a voice.
- Concept generation with estimated and exact cost, batches of 20, four-layer duplicate prevention (history in the cached prompt, local
  similarity, optional semantic check with embeddings, compressed history), approve (A) / delete (D), Trash with permanent delete.
- Concept to video: HyperFrames (default), Remotion (after its license is accepted) and Revideo (experimental); model-written code with a
  safety check and one repair; narration with Supertonic 3 (local, free), the optional Piper Turkish voice (non-commercial) or OpenAI
  speech; subtitles (burned in and .srt); a narration text file; scene images from your samples or an image model (fal, OpenAI, Z.ai).
- Produced videos: thumbnail, details with cost per step and voice notes, play, open folder, delete with an optional move to the recycle bin.
- Providers: Anthropic, OpenAI, OpenRouter, Z.ai, Mistral, DeepSeek, fal; step-by-step key guides; free connection test.
- Encrypted database (SQLite3 Multiple Ciphers; DPAPI, Linux keyring or a master password), daily password-protected backups (last 10),
  API keys never in backups. English and Turkish interface. Bottom-right notifications and a log panel.

## Known limits

- Videos up to 3 minutes; no long horizontal videos.
- The files are not code-signed (Windows SmartScreen asks once).
- Revideo is experimental. On Linux ARM64, HyperFrames and Revideo need the system Chromium (Remotion brings its own browser).
- The pinned ffmpeg build comes from a dated BtbN release; if that release is removed, the install fails with a clear message and a new
  version of TM Concept pins a newer build (on Linux the distribution's ffmpeg is used).
- No real request to any AI provider was made during development tests (they use fake HTTP). Model names and prices are from the
  providers' pages on 5 Nov 2026; check Settings → Models on first use.
- Videos open in the system's video player; there is no player inside the app yet.
