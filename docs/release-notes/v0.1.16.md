# TM Concept 0.1.16

[English](#english) · [Türkçe](#türkçe)

## English

### What changed since 0.1.15

**Local images on AMD, Intel and computers without a graphics card**
- 0.1.15 shipped only the NVIDIA CUDA build of stable-diffusion.cpp on Windows. On a computer without an NVIDIA card it could not
  start (exit code 0xC0000135, a missing DLL), and the video went on without images.
- The app now finds the graphics cards itself (maker, name, memory; Windows and Linux) and picks the build: NVIDIA CUDA, Vulkan
  (AMD, Intel, NVIDIA) or the processor. **Settings → General → Image acceleration** shows the card it found and lets you choose
  another build.
- The model picker shows in green whether a local image model fits the card's memory and in red when it does not. Memory flags follow
  the card. A new **Z-Image Turbo (full quality)** model is offered for cards with 16 GB or more.
- On Windows every build needs the Microsoft Visual C++ 2015–2022 runtime (x64). If it is missing, the video stops before any paid
  call and the message gives the download link.

**Custom servers (OpenAI-compatible)**
- Settings → API keys → **Custom server (OpenAI-compatible)**: any http or https address (Lemonade Server, Ollama, LM Studio,
  llama.cpp, vLLM on your computer, another computer on your network, or a remote server or service), an optional API key, and its
  models (listed by the server or typed by hand), each with its context, max answer, image and JSON-schema settings.
- These models are offered in every text step: topic suggestions, concepts, AI edits, video code, image prompts, sample-image
  descriptions. A saved server can be edited. Guide: [docs/api-keys.md](../api-keys.md#custom-server-openai-compatible).

**Errors are shown, not swallowed**
- A button that cannot run now says why (for example "Suggest topics" with no profile, no key or no model chosen).
- Warnings and errors from the app's log appear in the activity panel at the bottom.
- An unexpected failure in any step (images, narration, …) stops the video before the paid video code step and shows the reason.
  Expected cases (images turned off, no sample images) stay warnings.

**After an update**
- When a new version starts for the first time it asks: **Update components** (reinstalls only what is missing or changed),
  **Reinstall from scratch** (moves the components folder to the recycle bin and installs again), or **Later**. The database,
  profiles, concepts and videos are never touched. The same reinstall is under Settings → General.
- The components folder is `%LOCALAPPDATA%\TM Concept\tools` on Windows and `~/.local/share/tm-concept/tools` on Linux.
  If images failed on 0.1.15 with a non-NVIDIA card, choose **Reinstall from scratch** (or delete that folder) and let the app
  install the build it picks now.

**Not yet tried on real hardware:** the Vulkan build on an AMD card, the full-quality Z-Image model and the 8–12 GB memory settings.
Reports are welcome.

## Türkçe

### 0.1.15'ten bu yana değişenler

**AMD, Intel ve ekran kartı olmayan bilgisayarlarda yerel görsel**
- 0.1.15 Windows'ta stable-diffusion.cpp'nin yalnız NVIDIA CUDA sürümünü kuruyordu. NVIDIA kartı olmayan bilgisayarda bu sürüm
  açılamıyordu (çıkış kodu 0xC0000135, eksik DLL) ve video görselsiz devam ediyordu.
- Program artık ekran kartlarını kendisi buluyor (üretici, ad, bellek; Windows ve Linux) ve sürümü seçiyor: NVIDIA CUDA, Vulkan
  (AMD, Intel, NVIDIA) ya da işlemci. **Ayarlar → Genel → Görsel hızlandırma** bulunan kartı gösterir ve başka bir sürüm seçtirir.
- Model seçici, yerel görsel modelinin kartın belleğine sığdığını yeşille, sığmadığını kırmızıyla gösterir. Bellek ayarları karta göre
  yapılır. 16 GB ve üstü kartlar için yeni **Z-Image Turbo (tam kalite)** modeli var.
- Windows'ta her sürüm Microsoft Visual C++ 2015–2022 çalışma zamanını (x64) ister. Eksikse video ücretli çağrıdan önce durur ve
  mesaj indirme bağlantısını verir.

**Özel sunucular (OpenAI uyumlu)**
- Ayarlar → API anahtarları → **Özel sunucu (OpenAI uyumlu)**: herhangi bir http ya da https adresi (bilgisayarındaki Lemonade
  Server, Ollama, LM Studio, llama.cpp, vLLM; ağındaki başka bir bilgisayar ya da uzak bir sunucu veya hizmet), isteğe bağlı API
  anahtarı ve modelleri (sunucunun listelediği ya da elle yazılan); her model için bağlam, en uzun yanıt, görsel ve JSON şeması ayarı.
- Bu modeller her metin adımında sunulur: konu önerileri, konseptler, yapay zekâ düzenlemeleri, video kodu, görsel istemleri, örnek
  görsel açıklama. Kayıtlı sunucu düzenlenebilir. Rehber: [docs/api-keys.tr.md](../api-keys.tr.md#özel-sunucu-openai-uyumlu).

**Hatalar yutulmuyor, gösteriliyor**
- Çalışamayan bir düğme artık nedenini söylüyor (ör. profil, anahtar ya da model seçilmemişken "Konu öner").
- Program günlüğündeki uyarı ve hatalar alttaki etkinlik panelinde görünür.
- Herhangi bir adımda olağan dışı bir hata (görsel, seslendirme…) videoyu ücretli video kodu adımından önce durdurur ve nedenini
  gösterir. Beklenen durumlar (görseller kapalı, örnek görsel yok) uyarı olarak kalır.

**Güncellemeden sonra**
- Yeni sürüm ilk açıldığında sorar: **Bileşenleri güncelle** (yalnız eksik ya da değişmiş olanları kurar), **Sıfırdan yeniden kur**
  (bileşen klasörünü geri dönüşüm kutusuna taşır, yeniden kurar) ya da **Sonra**. Veritabanına, profillere, konseptlere ve videolara
  asla dokunulmaz. Aynı yeniden kurulum Ayarlar → Genel'de de var.
- Bileşen klasörü Windows'ta `%LOCALAPPDATA%\TM Concept\tools`, Linux'ta `~/.local/share/tm-concept/tools`. NVIDIA dışı bir
  kartta 0.1.15 ile görsel yapılamadıysa **Sıfırdan yeniden kur**'u seç (ya da o klasörü sil) ve programın şimdi seçtiği sürümü
  kurmasına izin ver.

**Henüz gerçek donanımda denenmedi:** AMD kartta Vulkan sürümü, tam kalite Z-Image modeli ve 8–12 GB bellek ayarları.
Geri bildirimler memnuniyetle karşılanır.
