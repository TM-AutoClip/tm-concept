# Built-in Turkish pronunciations: foreign names a Turkish text keeps in their own spelling, written the way Turkish reads letters, so a
# voice told the language "tr" reads them as Turkish speakers say them ("Viking" was read as English "vayking"). One "word=spoken" per
# line; a whole word only ("Viking'ler" yes, "Vikingler" no; the suffix after the apostrophe is agreed with the spoken form: "Google'ın"
# is read "Gugılın"). Upper and lower case do not matter, except for a line that starts with "!": "!IT=Ay Ti" matches only "IT" as
# written, so the word "it" of a sentence stays. "## heading" starts a category of the settings list. The user's own word of the same
# spelling replaces a line here. A spoken form has no digits and at most 60 characters. Numbers, dates, most units and other
# abbreviations are read by rules after this list (they are not listed here).
